# Commands and keybindings

## zsh

| Command            | Description      |
| ------------------ | ---------------- |
| `set -o`           | List options     |
| `zle -al`          | List keybindings |

## fzf

| Keybinding             | Description                      |
| ---------------------- | -------------------------------- |
| `ctrl` + `t`           | List files and directories       |
| `option (right)` + `c` | List directories (`cd`: `enter`) |
| `ctrl` + `r`           | History                          |
